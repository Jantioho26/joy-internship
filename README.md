# Ultraverse — NFT Marketplace

Ultraverse is a responsive NFT marketplace web application featuring a modern, visually engaging interface inspired by digital collectibles and NFT trading platforms.  Collaborated with other students to create a dynamic webpage. 

Live Demo: https://joy-nft-marketplace.vercel.app/

## Technologies Used

- React — 17.0.2
- JavaScript (ES6+)
- HTML5
- CSS3
- Vercel 

## Features

- **NFT Marketplace Interface**: Modern layout designed for exploring digital collectibles.

- **NFT Collection Display**: Visually engaging presentation of NFT artwork and collections.

- **Responsive Design**: Interface designed to adapt to different screen sizes.

- **Interactive UI**: Modern styling and navigation inspired by NFT marketplace platforms.

### How to Run Locally

- git clone https://github.com/Jantioho26/joy-internship.git

- npm install

- npm run dev

- Open the local URL displayed in your terminal (localhost:3000)

- Deployed using Vercel.
