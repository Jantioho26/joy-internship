# Ultraverse — NFT Marketplace

Ultraverse is a responsive NFT marketplace web application featuring a modern, visually engaging interface inspired by digital collectibles and NFT trading platforms.

Live Demo: https://joy-nft-marketplace.vercel.app/

## Technologies Used

- React — version to confirm
- JavaScript (ES6+)
- HTML5
- CSS3
- Vercel — deployment

## Features

- **NFT Marketplace Interface**: Modern layout designed for exploring digital collectibles.

- **NFT Collection Display**: Visually engaging presentation of NFT artwork and collections.

- **Responsive Design**: Interface designed to adapt to different screen sizes.

- **Interactive UI**: Modern styling and navigation inspired by NFT marketplace platforms.

### How to Run Locally

Clone the GitHub repository and navigate to the project folder.

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in your terminal.

Deployment

Deployed using Vercel.
